# Rinx Matrix 注册与使用说明

注册和登录请访问 [https://auth.matrix.rinx.chat](https://auth.matrix.rinx.chat)。注册后，你的完整 Matrix 账号格式为 `@{user}:matrix.rinx.chat`，其中 `{user}` 是你注册时选择的用户名。

## 常用地址

| 用途                                 | 地址或格式                                                   |
| ------------------------------------ | ------------------------------------------------------------ |
| 注册与登录                           | [https://auth.matrix.rinx.chat](https://auth.matrix.rinx.chat) |
| 账号管理                             | [https://auth.matrix.rinx.chat/account/](https://auth.matrix.rinx.chat/account/) |
| 聊天客户端的服务器地址（Homeserver） | `https://matrix.rinx.chat`                                   |
| 完整 Matrix 账号（Matrix ID / MXID） | `@{user}:matrix.rinx.chat`（包含开头的 `@`）                 |

完整账号示例：

```text
@alice:matrix.rinx.chat
```

认证网站用于注册、登录和管理账号。日常收发消息需要使用支持本服务登录方式的 Matrix 聊天客户端。

## 如何注册

1. 打开 [https://auth.matrix.rinx.chat](https://auth.matrix.rinx.chat)，选择页面上的注册或创建账号入口。
2. 输入你希望使用的用户名。若页面单独要求“用户名”，填写例如 `alice`，无需自行加上 `@` 或 `:matrix.rinx.chat`。
3. 设置密码，并按页面要求填写邮箱等信息。建议使用独立、足够长的密码，并保存到密码管理器中。
4. 如果页面要求验证邮箱，请打开验证邮件并按照提示完成验证。未收到邮件时，可先检查垃圾邮件文件夹，再按页面提示重新发送。
5. 按页面提示完成注册。用户名为 `alice` 时，对应的完整账号是 `@alice:matrix.rinx.chat`。

用户名是否可用、允许的字符、密码要求和是否必须验证邮箱，以注册页面的校验结果为准。建议优先使用小写英文字母和数字，便于输入和分享。确认用户名后再提交，不要默认认为以后可以修改账号 ID。

## 用户名、完整账号和显示名称有什么区别

| 名称             | 示例                      | 用途                                                     |
| ---------------- | ------------------------- | -------------------------------------------------------- |
| 用户名           | `alice`                   | 注册时选择的账号名称；在要求用户名的登录表单中使用       |
| 完整 Matrix 账号 | `@alice:matrix.rinx.chat` | 向别人分享账号、让别人查找你或邀请你加入聊天室           |
| 显示名称（昵称） | `Alice` 或 `小艾`         | 聊天界面中显示的名字，可在客户端支持的个人资料设置中修改 |

`@` 和 `:matrix.rinx.chat` 都是完整账号的一部分。分享账号时请复制完整内容。`{user}` 只是占位符，实际账号中不包含花括号。

显示名称不用于唯一识别账号；修改昵称不会改变完整 Matrix 账号。初始显示名称可能带有 `⚡` 后缀，这不属于用户名或账号 ID。

## 如何在聊天客户端登录

1. 打开 Matrix 聊天客户端，选择登录。
2. 如果客户端要求选择服务器，使用 `matrix.rinx.chat`；如果要求填写服务器 URL，使用 `https://matrix.rinx.chat`。
3. 按客户端提示继续登录。出现“通过浏览器登录”或“单点登录（SSO）”等选项时，按提示打开认证页面。
4. 在 `auth.matrix.rinx.chat` 上完成登录，并按页面提示授权或返回客户端。
5. 回到客户端，确认已经进入自己的账号。

本服务使用统一认证。输入密码前，请确认认证页面地址为 `https://auth.matrix.rinx.chat`。不要把认证地址填写到客户端的 Homeserver 字段中。

如果客户端要求填写完整 Matrix ID，请输入 `@alice:matrix.rinx.chat` 这样的完整账号；如果只要求用户名，则按页面提示填写 `alice`。不同客户端的字段和按钮可能不同。

## 密码找回与账号管理

忘记密码时，请在 [认证网站](https://auth.matrix.rinx.chat) 的登录页面查找密码找回入口，并按照页面提示操作。当前部署配置已启用密码找回，实际能否完成找回取决于账号信息和邮件服务是否正常。

需要管理账号时，可打开 [账号管理页面](https://auth.matrix.rinx.chat/account/)，登录后使用页面提供的功能。建议确保账号中保存的邮箱可正常收信。

## 加密聊天与新设备

如果使用端到端加密聊天室，请按照客户端提示设置加密备份，并妥善保存恢复密钥或恢复口令。新设备登录时，可能需要通过已有设备验证，或使用恢复信息读取历史加密消息。

账号密码与聊天加密恢复信息用途不同。重置账号密码并不等于恢复历史加密消息；如果丢失所有已验证设备和恢复信息，部分历史消息可能无法解密。

不要向任何人提供密码、邮箱验证码或加密恢复密钥。

## 常见问题

### 别人应该用什么账号来找我？

分享完整 Matrix 账号，例如 `@alice:matrix.rinx.chat`，不要只发送昵称或 `alice`。

### 为什么登录时会跳到另一个域名？

聊天服务器地址是 `matrix.rinx.chat`，统一认证地址是 `auth.matrix.rinx.chat`。客户端跳转到该认证域名进行登录属于本服务的登录流程。

### 客户端无法登录怎么办？

先检查服务器是否填写为 `https://matrix.rinx.chat`，再确认客户端能完成浏览器认证或 SSO 登录。若客户端只显示直接输入密码的表单，可检查是否有其他登录方式；仍无法登录时，联系管理员并说明客户端名称、版本和报错内容。
