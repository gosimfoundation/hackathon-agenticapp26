# 9/26 实战演示:用 OctoLoop 调研比赛并做一个参赛应用

开课当天的一次完整演示:外环(强模型)写任务和验收,内环(octoscode + octos)执行,所有内环都在 herdr 里可见。演示覆盖两件事:

1. **调研**:三路内环并行,共 12 个 peer agent,读完比赛仓库与 10 个技术栈仓库,产出带 `文件:行号` 证据的报告,外环抽样核对后采认。
2. **做应用**:以 makepad 自带的天气 app 为起点做独立参赛应用 `octo-weather`,中文化、城市搜索、失败状态、日期修正,再按设计蓝图逐片接入 octos agent;每片都由外环在隔离环境复验、亲眼看截图后才放行。
